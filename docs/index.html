Workflow

三步完成一张可直接练琴的高清曲谱

抛弃繁琐的五线谱排版与 Word 对齐噩梦，专注在进唱字位与和弦本身。

01 / IMPORT

导入歌词或 AI 识谱

拖入本地 .lrc / .txt 歌词文件，自动识别编码、读取歌名与原唱并过滤制作人员行；或使用内置 AI 识谱 Prompt 将图片曲谱一键转成结构化曲谱导入。

02 / ARRANGE

标和弦、配六线谱、排段落

点字或纯键盘快速放置左手和弦，按需插入前奏/间奏六线谱与演奏技巧，使用叠行排版把主歌 1、主歌 2 紧凑收进同一页。

03 / EXPORT

高清导出与曲库归档

一键导出高清 PNG 长图或 A4 分页打印 / PDF，或另存 .xianpu.json 分享给琴友，同时自动归档到本地曲库。

Features

为吉他弹唱与指弹场景打磨的每一处细节

正式版 v1.2.0 已发布，涵盖从入门弹唱、全和弦乐理推演、CAGED 互动指板、指板练功房到进阶六线谱编排的完整能力。

AI 辅助

AI 识谱导入（弹唱谱 & 指弹谱）

无需配置 API Key，内置两套经过调优的专属 Prompt，配合任意多模态大模型即可把网图、纸质谱照片快速数字化。

  • 支持「弹唱谱（歌词 + 和弦）」与「指弹谱（纯六线谱 / 多页）」双模板
  • 自动从整段 AI 回复中提取 JSON，支持新建或追加到当前曲谱
  • 同样兼容直接粘贴 .xianpu.json 进行跨设备分享
和弦记谱

左手和弦标记与按调自定义指法

在进唱字位上方或字前精准落点和弦，支持拖拽调整、全谱移调与自定义指法图。

  • 内置各调常用和弦快捷条，支持 Fmaj7、C9、Am7sus4、D/F# 等任意记号并由乐理引擎自动推导指法图
  • 支持右键一键「换把位」切换多个可用指法，也可按调号自定义微调并保存
  • 支持 ♭-1 / ♯+1 半音移调与按目标调名批量转调
六线谱 TAB

独立六线谱编辑器与丰富演奏技巧

在歌词前奏、间奏、尾奏或任意段落后嵌入可选六线谱区块，与弹唱歌词自然衔接。

  • 支持自定义拍号、小节列数、节奏符干、附点、休止符与反复记号
  • 涵盖下扫/上扫/切音/琶音、P.M. 制音、击弦 H、勾弦 P、滑音 S、推弦、泛音与揉弦
  • 支持联动编辑（Ripple Editing），大幅减少调小节时的重复劳动
智能排版

段落编排、多段叠行与单页紧凑布局

针对常见流行与民谣结构优化版面密度，让一首歌尽量用更少的翻页清晰呈现。

  • 自动分析前奏/主歌/副歌/桥段结构，支持段落排序与引用段插入
  • 谱面原位直接打字改词（支持叠行逐遍修改与断句，和弦自动跟随字位平移）
  • 多段主歌歌词叠行显示，配备专用字位对齐编辑器
  • 合行紧凑 / 逐句单行 / 自动双栏自由切换，适配 13 寸小屏与高分屏
练琴辅助

练琴专注模式、自动滚屏与节拍器

按 F5 一键进入练琴模式，隐藏编辑栏、放大谱面，看谱与打拍子两不误。

  • 多档速度自动滚屏，Space 随时暂停 / 继续
  • 零依赖木鱼音色节拍器，联动谱头 BPM，支持 4/4、3/4、6/8
  • A4 智能分页打印 / 导出 PDF，高清 PNG 长图无选中框
乐理指板

CAGED 五色拼图、全景指板与个人乐理本

按 F6 进入交互式 0–17 品原声吉他指板工作台，把音阶、指型、和弦解剖与当前曲谱打通。

  • 5 色咬合 CAGED 拼图边界、21 种音阶、9 种调弦、每弦两音胶囊与点击拨弦发声
  • 内置 8 节互动 CAGED 课、六弦三行和弦解剖表与和弦进行四色靶向音教练
  • 「⚡ 指板练功房」动态生成模进、重音移位、3–6度跳音、顺阶琶音与同把位五度圈六线谱跟练
  • 支持一键读取当前曲谱和弦、记录指板快照到「我的乐理收集本」随曲库持久化
曲库与数据

本地曲库、自动快照与多设备同步

谱头直接编辑歌名、原唱、调号与 BPM，所有曲谱只保存在你自己的电脑上。

  • 按歌名、原唱、调号、分类或歌词关键词实时搜索，支持收藏与分类
  • 自定义数据目录（可指向网盘同步盘），每次保存自动保留最近 5 份历史快照
  • 主谱面 Ctrl+Z / Ctrl+Y 撤销重做，一键导出整库 / 从备份恢复

三步用好 AI 识谱导入

手里只有截图或扫描谱？不用逐字重抄：

  1. 在应用顶部点击「AI 识谱」，选择弹唱谱或指弹谱模式并点击「复制 Prompt」。
  2. 将 Prompt 连同曲谱图片发给任意支持识图的 AI（如 Gemini、ChatGPT、Claude 等）。
  3. 复制 AI 返回的完整内容粘贴回弹窗，自动提取 JSON 并即时渲染成可编辑曲谱。
