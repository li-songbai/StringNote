# 弦笺 · StringNote

**弦笺 (StringNote)** 是一款面向 Windows 的轻量原生吉他记谱桌面应用，专注于**弹唱谱与指弹六线谱的极简制作、排版与高清导出**。

🌐 **项目主页**：[https://li-songbai.github.io/StringNote/](https://li-songbai.github.io/StringNote/)  
📦 **最新版下载**：[GitHub Releases](https://github.com/li-songbai/StringNote/releases/latest)（当前正式版 v1.2.0）

---

## 核心特性

### 1. 智能导入与 AI 识谱
- **AI 识谱导入**：内置「弹唱谱（歌词 + 和弦）」与「指弹谱（纯六线谱 / 多页）」两套专属 Prompt。一键复制 Prompt 连同曲谱图片发给任意多模态 AI，将返回的 JSON 直接粘贴即可自动解析导入，支持新建曲谱或追加到当前曲谱。
- **LRC / 文本歌词导入**：自动识别 UTF-8 / GBK / GB18030 编码，提取 `[ti:]` 歌名、`[ar:]` 原唱与 `原调 / 选调 / 变调夹` 信息，自动过滤作词/作曲/编曲等制作人员行并清理逐字时间戳。
- **拖拽即开**：支持直接将 `.lrc`、`.txt`、`.xianpu.json` 文件拖入主窗口打开。

### 2. 高效左手和弦记谱与自定义指法
- **点字即填**：单击任意歌词字位，正上方弹出轻量输入框与本调常用和弦快捷按钮，支持键入任意和弦（如 `C`、`Am7`、`Fmaj7`、`G/B`、`D/F#`、`Bm7-5`、`Cadd9` 等）回车确认。
- **谱面原位改词**：双击任意一句歌词（含多段叠行第 1/2 遍）、按 `F2`，或开启工具栏「Ｉ 改词」模式单击歌词，即可直接在纸面原位置打字修改；增删文字时该句后续和弦**自动跟随对应歌词字平移**，按 `Shift+Enter` 可从光标处断句拆成两行（和弦同步拆分），按 `↑` / `↓` 连续切换上下句。
- **纯键盘高速走位**：在谱面使用方向键 `←` `→` `↑` `↓` 移动进唱字位，直接按 `A`–`G` 呼出输入；按 `Tab` / `Shift+Tab` 连续跳字填谱。
- **连点填谱 & 自由拖拽**：开启「连点填谱」可批量放置同一和弦；已放置的和弦可直接拖拽到其他进唱字位，支持字上与字前定位。
- **主谱面撤销 / 重做**：支持 `Ctrl+Z` / `Ctrl+Y`（及工具栏按钮）随时撤销与重做和弦标记、移调、改词、段落编排与六线谱改动。
- **全和弦乐理自动推导指法图 & 一键换把位**：输入任意延伸、变化或斜杠转位和弦（如 `C9`、`Am7sus4`、`Fsus2`、`Gsus4`、`Ebmaj7`、`F#m7-5`、`E7#9`、`Dm7/G` 等），无需手动绘制，内置乐理 + 吉他指板人体工学引擎自动推导标准指法与横按标记，并支持在谱面右键或弹窗中一键「↻ 换把位」切换多个可用把位。
- **按调自定义和弦与指法图**：支持按调号新增常用和弦，并在自动推导的基础上微调个人习惯按法，自动保存到本地曲库。
- **一键移调**：支持全谱 `♭-1` / `♯+1` 半音升降调，或直接按目标调名批量移调，保留全部换和弦位置。
- **和弦名 / 指法图切换**：支持在谱面上自由切换显示纯和弦名、六弦指法图及顶部和弦一览。

### 3. 可选六线谱（TAB）与演奏技巧
- **独立六线谱编辑器**：可为歌曲添加**前奏、间奏、尾奏**或任意段落后的六线谱区块，支持自定义拍号、小节列数、反复记号、节奏符干与休止符。
- **丰富的演奏技巧标注**：支持扫弦方向（下扫/上扫/切音/琶音）、制音（P.M.）、击弦（H）、勾弦（P）、滑音（S / 滑入 / 滑出）、延音线、倚音、推弦/释放、自然与人工泛音、揉弦、闷音等。
- **联动编辑（Ripple Editing）**：编辑小节和音符时保持节奏对齐，并可在主谱面与导出 PNG 中所见即所得呈现。

### 4. 段落编排与多段叠行排版
- **自动段落识别与编排**：内置段落结构分析，支持标记前奏、主歌、副歌、桥段、尾奏及反复次数，并可随时调整顺序或插入引用段落。
- **多段歌词叠行**：针对主歌 1 / 主歌 2 旋律与和弦相同的曲目，支持叠行显示多段歌词并提供专用对齐编辑器，大幅节省页面空间。
- **单页流式紧凑排版**：默认智能合行紧凑排布，同时提供**自动双栏 / 单栏 / 双栏对照**切换，避免导出长图过长。

### 5. 本地曲库、练琴辅助与高清输出
- **谱头信息**：在谱面顶部直接编辑歌名、原唱、原调 / 选调 / 变调夹与可选 BPM，导出 PNG / 打印时一并呈现。
- **可折叠本地曲库**：支持按歌名、原唱、调号、分类或歌词关键词实时搜索，支持 `★ 收藏`、自定义分类、新建/副本/重命名/批量改词/删除。
- **自定义数据路径 & 自动历史快照**：默认存放于 `%LocalAppData%\Xianpu\library.json`，可在「设置与备份」中自由切换存放目录（支持直接指向网盘同步盘实现多设备同步）；每次保存自动在 `backups/` 保留最近 5 份历史快照，并支持**一键导出整库 / 从备份恢复**。
- **A4 分页打印 / 导出 PDF & 高清 PNG**：支持智能防断行分页打印 A4 曲谱或调用 `Microsoft Print to PDF` 输出矢量 PDF；一键导出高清无选中框 PNG 图片，也支持 `.xianpu.json` 单曲分享。
- **练琴专注模式（`F5`）**：一键隐藏编辑栏、放大谱面，并浮出自动滚屏与节拍器控制条，再按 `F5` 返回编辑。
- **看谱自动滚屏 & 内置节拍器**：集成多档速度自动滚屏（`Space` 空格随时暂停/继续）与零依赖木鱼音色节拍器（联动谱头 `BPM`，支持 `4/4`、`3/4`、`6/8` 拍号切换）。
- **轻量桌面体验**：基于 .NET 10 WPF 原生构建，适配 13 寸小屏与高分屏缩放，配备自定义无边框标题栏、Windows 系统托盘驻留与应用内自动检查更新。

### 6. 乐理指板与 CAGED 系统工作台（`F6`）
- **全景交互式 0–17 品吉他指板**：内置枫木 / 玫瑰木指板切换、9 种常用调弦（Standard / Drop D / DADGAD / Open G 等）、变调夹联动与当前曲谱调号同步；内置零依赖 Karplus-Strong 原声吉他物理合成音色，点击任意品格即可拨弦发声。
- **CAGED 五色拼图 & 3NPS 七把位双坐标系**：支持在全指板上自由切换 C / A / G / E / D 五色咬合把位框与 **3NPS（每弦三音）1～7 把位斜向跑道**，支持「每弦两音」胶囊与三种圆点标注（调内音级 / 音名 / 音程）。
- **互动乐理与 CAGED 全景实战课（8 大单元 · 24 课）**：系统覆盖指板八度几何与 B 弦偏移规律、三/七/挂留/延伸和弦色彩、关系大小调与蓝调/教会调式特征音、大/小调 CAGED 与 3NPS 双核导航、顺阶功能与五度圈、斜杠低音线/副属和弦/同主音小调借用、以及变调夹双向换算与零基础听音定调扒谱四步法；配备 **📌 核心口诀卡**、**🎧 AB 听感对比试验台**、**🎯 指板随堂点按闯关**、学习进度持久化与一键跳转练功房/解剖库/进行台实操传送门。
- **和弦解剖库**：支持「调内 1–7 级 / 自由 12 音」与「基础 / 探索（九/挂留/减/半减等）」切换，提供指法图、六弦三行对齐解剖表（和弦音程 / 调内音级 / 实际音名）、`< 按法 1/N >` 把位切换以及扫弦 / 分解试听。
- **和弦进行 & 靶向音教练**：内置 8 套经典和弦进行并支持一键「📥 读取当前曲谱和弦」，可按 BPM 循环播放并在指板上以四色高亮当前和弦靶向音（根音 / 和弦音 / 色彩音 / 经过音），同时提供「✨ 更顺滑（低音线/转位）」与「✨ 更丰富（七/九/挂留）」编配建议。
- **⚡ 指板练功房（32 套渐进课程 · 每日日课连播 · 12 调五度圈转盘 · A4 练习册）**：涵盖跨把位滑音高速路、模进与重音移位、3～6度跳音、顺阶三/七和弦反向琶音及自选把位 5/12 调五度圈闭环；内置 **「🔥 每日 15 分钟自动连播日课」**（含组间换手倒数与连续打卡统计）、**BPM 速度成长折线轨迹**、可视化 12 调五度圈转盘 HUD 以及 **多课合集 A4 分页打印 / PDF 练习册导出**。
- **我的乐理收集本**：一键把当前指板的调号、音阶、CAGED 指型、和弦与变调夹状态拍成快照，配合个人笔记保存到本地曲库（`library.json`），随时一键还原整块指板继续练琴。

### 常用快捷键

| 快捷键 | 说明 |
| --- | --- |
| `←` `→` `↑` `↓` | 在谱面进唱字位间移动 |
| 双击歌词 / `F2` | 在谱面纸张原位编辑当前歌词（`Enter` 保存，`Shift+Enter` 断句，`↑`/`↓` 切句） |
| `A`–`G` | 直接呼出和弦输入框（`Enter` 确认） |
| `Tab` / `Shift+Tab` | 跳到下一 / 上一字位连续填谱 |
| `Ctrl+Z` / `Ctrl+Y` | 撤销 / 重做主谱面操作 |
| `F5` | 进入 / 退出练琴专注模式 |
| `F6` | 进入 / 退出「🎼 乐理指板」工作台 |
| `Space` | 自动滚屏时暂停 / 继续 |
| `Ctrl` + 滚轮 | 缩放谱面 |

## 安装与更新

### 方式一：安装程序（推荐）
前往 [GitHub Releases](https://github.com/li-songbai/StringNote/releases) 下载最新版 `StringNote-Setup-<version>.exe`：
- 采用每用户（Per-User）安装模式，默认安装到 `%LocalAppData%\Programs\StringNote`，**无需管理员 UAC 弹窗**。
- 自动创建开始菜单与桌面快捷方式，并关联 `.xianpu.json` 文件双击打开。
- 支持应用内检查更新，自动下载新版安装包并静默覆盖重启。

> 从 `0.1.0-beta.x` 升级：在应用内「检查更新」即可直接升级到正式版，或下载新版安装包覆盖安装；曲库数据存放在 `%LocalAppData%\Xianpu`（或自定义目录），升级不受影响。

### 方式二：免安装便携版
下载 `StringNote-Portable-win-x64-<version>.zip`，完整解压后直接运行 `Xianpu.Desktop.exe` 或 `Start-Xianpu.cmd`（自包含 .NET 10 运行时，无需额外安装运行环境）。

## 本地构建（Windows）

需要安装 [.NET 10 SDK](https://dotnet.microsoft.com/download/dotnet/10.0)（Windows x64）：

```powershell
# 直接构建
dotnet build app/Xianpu.Desktop/Xianpu.Desktop.csproj

# 框架依赖打包（生成便携 ZIP）
pwsh -ExecutionPolicy Bypass -File .\Build.ps1

# 自包含单文件打包（如本机已安装 Inno Setup 6，将同时生成安装包）
pwsh -ExecutionPolicy Bypass -File .\Build.ps1 -SelfContained -Version 1.0.0
```

也可直接双击根目录的 [启动弦谱.cmd](启动弦谱.cmd) 快速启动本地构建产物。

## 开发说明

- 架构：WPF + 渐进式 MVVM（`CommunityToolkit.Mvvm`），视图模型位于 `app/Xianpu.Desktop/ViewModels/`，纯逻辑服务位于 `Services/`。
- 单元测试：`dotnet test tests/Xianpu.Desktop.Tests`（覆盖移调、LRC 导入、段落分析、AI 导入、曲库备份与视图模型）。
- 每次 Push / PR 会在 GitHub Actions `windows-latest` 上自动构建并运行测试；`main` 分支要求 `build-windows` 检查通过后才能合并。
- 更多协作约定见 [AGENTS.md](AGENTS.md)。

## 自动发布流水线

仓库已配置 GitHub Actions（[`.github/workflows/release.yml`](.github/workflows/release.yml)）：

1. 推送语义化版本标签（`v*`）：
   ```bash
   git tag v1.0.1
   git push origin main --tags
   ```
2. Actions 将在 `windows-latest` 上自动完成 .NET 10 `win-x64` 单文件发布、便携包压缩、Inno Setup 6 安装包编译，并自动创建 GitHub Release 与 Release Notes。
3. 亦可在 GitHub 仓库的 **Actions → Release StringNote → Run workflow** 中手动触发。

> 开发者与 AI 协作者请参阅 [AGENTS.md](AGENTS.md) 了解代码架构与开发约定。
